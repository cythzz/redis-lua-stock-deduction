# 压测记录模板

运行环境不同会显著影响结果，因此仓库不填写虚构吞吐量。请启动完整环境后执行：

```powershell
k6 run .\performance\order-spike.js
```

面试展示时记录以下信息：

| 项目 | 结果 |
| --- | --- |
| 测试时间 | 待实测 |
| CPU / 内存 | 待实测 |
| 请求速率 | 100 requests/s，持续 30 秒 |
| P95 响应时间 | 待实测 |
| 错误率 | 待实测 |
| 初始化库存 | 1000 |
| 最终库存 | 待实测，必须大于等于 0 |
| 成功订单数 | 待实测，必须小于等于 1000 |

压测后同时保存 k6 摘要、`/actuator/prometheus` 指标和 Grafana 截图，便于说明限流、库存不超卖及 Kafka 消费积压情况。
